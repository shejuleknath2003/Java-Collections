when we are removing objects from the collection, the remove method used to remove elements from collection will internally call the equals method to compare and then remove.
note:
===
in wrapper classes and string class equals() method is already overridden to compare based on values.


 Integer objects:
=============
package Collectionsbatch1.Remove;

import java.util.ArrayList;

public class DemoRemove 
{
	public static void main(String[] args) 
	{
		ArrayList al=new ArrayList();//collection type object
		al.add(10);
		al.add(20);
		al.add(30);
		al.add(40);
		al.add(50);
		System.out.println("before "+al);
		//list interface method will be called
//		al.remove(30);//considers it as index
		
		//Collection interface method
		al.remove((Integer)30);//considers it as object
		System.out.println("after "+al);
		
	}

}
o/p:
===
before [10, 20, 30, 40, 50]
after [10, 20, 40, 50]

REMOVING CUSTOM OBJECT:
==================================
If we want to remove custom object we have to override equals method in that class so that it compares the values instead of references.

package Collectionsbatch1;

import Collectionsbatch1.Remove.Employee;

public class Employee 
{
	String name;
	int age;
	public Employee(String name, int age) {
		super();
		this.name = name;
		this.age = age;
	}
	@Override
	public String toString() {
		return "Employee [name=" + name + ", age=" + age + "]";
	}
	//overriding equals method to compare values
	public boolean equals(Object o)
	{
		Employee e=(Employee)o;
		if(!this.name.equals(e.name))
			return false;
		if(this.age!=e.age)
			return false;
		return true;
		
	}

}

package Collectionsbatch1.Remove;

package ArrayList;

import java.util.ArrayList;
import java.util.Scanner;

public class RemoveTheElementBasedOnAtrribute {

	public static void main(String[] args) {
		ArrayList<Employee> al = new ArrayList<Employee>();

		al.add(new Employee("abc", 101));
		al.add(new Employee("bcd", 102));
		al.add(new Employee("efg", 103));
		al.add(new Employee("xyz", 104));
		Scanner sc = new Scanner(System.in);
		System.out.println("Enter the id to be removed :");
		System.out.println(removeEmp(al, sc.nextInt()));
	}
	
	public static ArrayList<Employee> removeEmp(ArrayList<Employee> c,int key)
	{
		Employee e1 = null;
		for(Employee e : c)
		{
			if(key==e.salary)
			{
				e1=e;
//				c.remove(e);//ConcurrentModificationException
				break;
			}
		}
		c.remove(e1);
		return c;
	}
}
