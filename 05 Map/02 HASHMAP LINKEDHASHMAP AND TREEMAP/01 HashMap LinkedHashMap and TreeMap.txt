HashMap:
=============
It is an implementation class of Map and it will work based on a hashing mechanism.

HashMap uses an array of buckets where each bucket stores a linked list of nodes.
Initial Capacity: Default size of the array (16 buckets).
Load Factor: 0.75 (75%) → When the map reaches 75% capacity, it resizes (doubles the size).

Constructors:
=======
HashMap()
Constructs an empty HashMap with the default initial capacity (16) and the default load factor (0.75).
HashMap(int initialCapacity)
HashMap(int initialCapacity, float loadFactor)
HashMap(Map<? extends K,? extends V> m)

Characteristics:
========
-> Stores key-value pairs	Each key is mapped to a value.
-> No duplicate keys	Keys must be unique, but values can be duplicated.
-> Allows null keys & values	One null key is allowed, multiple null values are allowed.
-> Unordered	Does not maintain insertion order.
-> Fast operations (O(1))	Average time complexity for put(), get(), remove() is O(1).
-> Not Thread-Safe	Use Collections.synchronizedMap() or ConcurrentHashMap for thread safety.

Note: There is no extra methods in HashMap.
-->If a key already exists, put(K key, V value) replaces the old value.

Note:
======
What if Two Keys are Identical?
If the keys are equal (equals() returns true), the new value replaces the old value.
If they have the same hash but are different keys, they are stored separately.

LinkedHashMap:
==========
LinkedHashMap is a subclass of HashMap that maintains the insertion order of elements using a doubly linked list.

Characteristics:
-> Maintains insertion order	Unlike HashMap, it preserves the order of key-value pairs.
-> Uses a doubly linked list	Maintains a linked list of entries to preserve order.
-> Allows null keys & values	Just like HashMap, it allows one null key and multiple null values.
-> Faster iteration	Since it maintains a linked list, iterating over elements is faster than HashMap.
-> Not Thread-Safe	Use Collections.synchronizedMap() or ConcurrentHashMap for thread safety.

Constructors:
LinkedHashMap()- Constructs an empty insertion-ordered LinkedHashMap instance with the default initial capacity (16) and load factor (0.75).
LinkedHashMap(int initialCapacity)
LinkedHashMap(int initialCapacity, float loadFactor)
LinkedHashMap(int initialCapacity, float loadFactor, boolean accessOrder)
LinkedHashMap(Map<? extends K,? extends V> m)
-> Fast lookups and insertions (O(1)).
-> Iteration is faster than HashMap because of the linked list.

 Conclusion
-> LinkedHashMap preserves insertion order using a doubly linked list.
-> Fast operations (O(1)), but slightly slower than HashMap due to extra memory usage.
-> Supports access-order mode for LRU caching.
-> Not thread-safe (Use ConcurrentHashMap for multi-threading)

TreeMap:
===========
TreeMap is a class and It is a Red-Black Tree based implementation of Map, where elements (key-value pairs) are sorted based on the keys.
  
Characteristics:
-> Stores key-value pairs	Each key is mapped to a value.
-> Sorted order	Keys are stored in ascending order by default.
-> Uses Red-Black Tree	Provides O(log n) complexity for operations.
-> No duplicate keys	Keys must be unique, but values can be duplicated.
-> Does not allow null keys	Unlike HashMap, it throws a NullPointerException for null keys.
-> Thread-Unsafe	Needs external synchronization for thread safety.
-> Implements NavigableMap	Provides methods for range searches and closest matches.

Constructors:
TreeMap()- Initial capacity is Zero.
TreeMap(Comparator<? super K> comparator)
TreeMap(Map<? extends K,? extends V> m)

Extra Methods:
firstKey()	Returns the smallest key.
lastKey()	Returns the largest key.
higherKey(K key)	Returns the next higher key.
lowerKey(K key)	Returns the next lower key.
ceilingKey(K key)
foortKey()
descendingKeySet()

Note:The tree automatically balances itself after insertions and deletions.
-> Each node contains key, value, left child, right child, and parent reference.
-> If a collision occurs (same key), it replaces the value instead of storing duplicates.

package Collection.afternun.Map;
import java.util.Objects;
public class Student implements Comparable<Student>
{
	public int id;
	String name;
	int age;
	public Student(int id, String name, int age) {
		super();
		this.id = id;
		this.name = name;
		this.age = age;
	}
	@Override
	public String toString() {
		return "Student [id=" + id + ", name=" + name + ", age=" + age + "]";
	}
	
	public boolean equals(Object o)
	{
		Student s=(Student)o;
		return this.hashCode()==s.hashCode();
	}
	
	public int hashCode()
	{
		return Objects.hash(id,name,age);
	}
	@Override
	public int compareTo(Student o) 
	{
		return this.id-o.id;
	}
}
