Queue:-
--------
--> java.util package.
--> used to represent FIFO (First-In-First-Out).elements are processed in the order they are added.

Application:
-------------
Order Processing Systems: Orders are handled in the order they are received.
Ticket Booking Systems: Users are queued during high-demand booking (e.g., trains, concerts).
Task Scheduling: Queues are used in job/task schedulers to manage execution.
Message Queues: Used for inter-process communication in distributed systems 
Printer Queue: Documents are printed in the order they are received.
Customer Service / Call Center: Calls are answered in the order they arrive.

Methods in Queue:
-----------------
| Method       | Description                                         |
| ------------ | --------------------------------------------------- |
| ` E add(E e)`   | Inserts element; throws exception if fails  //  throws IllegalStateException: if Queue is full
| `boolean offer(E e)` | Inserts element; returns `false` if fails     
| `E remove()`   | Removes and returns head; throws exception if empty | // No such element exception
| `E poll()`     | Removes and returns head; returns `null` if empty   |
| `E element()`  | Retrieves head; throws exception if queue is empty  |// No such element exception
| `E peek()`     | Retrieves head; returns `null` if queue is empty    |

import java.util.Queue;
import java.util.PriorityQueue;

public class Demo {
    public static void main(String[] args) {

        Queue<Integer> q = new PriorityQueue<>();

        q.add(30);
        q.add(10);
        q.add(20);

        System.out.println("Queue: " + q);

        System.out.println("remove(): " + q.remove());
        System.out.println("poll(): " + q.poll());

        System.out.println("element(): " + q.element());
        System.out.println("peek(): " + q.peek());

        System.out.println("Final Queue: " + q);
    }
}

Queue: [10, 30, 20]

element(): 30
