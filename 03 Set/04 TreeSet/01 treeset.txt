TreeSet:
==========
When ever we want arrange the elements in some sorting order we can  go with TreeSet.

Internal Implementation of TreeSet: 

Internally, TreeSet is backed by a TreeMap, where:
Keys are the elements of the set.
Values are dummy objects (PRESENT).

Constructors: 
TreeSet()
TreeSet(Collection)
TreeSet(Comparator)

Characteristics:
========
->It stores elements in sorted order and uses a self-balancing Red-Black Tree for internal implementation.
->There is no initial capacity.
->Ordered Elements	-->Elements are stored in ascending order (sorted order).
->No Duplicates	        -->TreeSet does not allow duplicate elements.
->Implements SortedSet & NavigableSet -->Provides additional methods for navigation (higher(), lower(), etc.).
->Red-Black Tree	        -->Internally uses a self-balancing Red-Black Tree for efficient operations.
->Null Values?	        -->Not allowed in Java 7+ (throws NullPointerException).
->Thread Safety	        -->Not synchronized ()(Use Collections.synchronizedSortedSet() for thread safety).

Note:
=======
-> TreeSet internally uses compareTo() or compare() method to sort.
->TreeSet is slower than HashSet (O(1) insert/search) but maintains sorting. 

Extra Navigational Methods:
==========
Method	        Description	                                  Example Output 
([10, 20, 30, 40])
first()  	Returns the first element	                             10
last()	        Returns the last element	                             40
higher(x)	Returns the next higher element after x	              numbers.higher(20) → 30
lower(x)	Returns the next lower element before x               numbers.lower(30) → 20

 When to Use TreeSet?
we Use TreeSet when:
->You need sorted elements.
->You need fast access to min/max elements.

Conclusion:
=====
 TreeSet stores unique elements in sorted order.
 Internally, it uses a Red-Black Tree (TreeMap).
 Performance is O(log n) for insertion, deletion, and searching.
 Supports navigation methods (higher(), lower(), etc.).
 Slower than HashSet but provides sorting.

Feature		TreeSet			HashSet			LinkedHashSet

Ordering	Sorted (Ascending)	Unordered	      Insertion Order
Null Allowed?	❌ No (Java 7+)	          ✅ Yes	        ✅ Yes
Performance	Slower (O(log n))	Fastest (O(1))	        Medium (O(1))
Implementation	Red-Black Tree	     Hash Table                 Hash Table + Doubly Linked List
                                 (Buckets + Linked List/Tree)	

Note:
For HashSet and LinkedHashSet we need to override hashCode() and equals()(Manditory)
But in TreeSet duplicates are removed with the help of compareTo() or compare(). (if both the objects are same it will return 0)

package Collection.sortingTreeset;
import java.util.HashSet;
import java.util.Objects;
import java.util.TreeSet;

import Collection.HashSet.Custom.Student;
public class Student implements Comparable<Student>
{
	int id;
	String name;			
	int age;
	public Student(int id, String name, int age) 
	{
		super();
		this.id = id;
		this.name = name;
		this.age = age;
	}
	@Override
	public String toString() {
		return "Student [id=" + id + ", name=" + name + ", age=" + age + "]";
	}
	public static void display(TreeSet<Student> hs)
	{
		System.out.println("============");
		for(Student s:hs)
		{
			System.out.println(s);
		}
		System.out.println("============");
	}

	//avoids duplicates as well as sorts
	@Override
	public int compareTo(Student o) 
	{
		return this.id-o.id;
	}
}

package Collection.sortingTreeset;
import java.util.Comparator;
public class SortBasedOnAge implements Comparator<Student>
{
	//SORTS AND AVOIDS DUPLICATES
	//SO DUPLICATE AGES WILL NOT BE ADDED
	@Override
	public int compare(Student o1, Student o2) 
	{
		return o1.age-o2.age;
	}
}


package Collection.sortingTreeset;
import java.util.TreeSet;
public class DemoSortingBasedOnAge
{
	public static void main(String[] args)
	{
